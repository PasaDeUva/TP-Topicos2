# Architectural Decision Records

Esta carpeta contiene las decisiones arquitectónicas del proyecto.

Crear un ADR cuando una decisión tenga impacto duradero sobre la arquitectura, los límites entre servicios, las tecnologías, los datos, el despliegue o la seguridad.

Usar la skill `create-adr` para revisar si ya existe una decisión equivalente y crear el siguiente archivo numerado:

```text
docs/adr/<numero>-<titulo-en-kebab-case>.md
```

Los ADRs se redactan en español y deben enlazarse desde la proposal o el design de OpenSpec relacionados.
