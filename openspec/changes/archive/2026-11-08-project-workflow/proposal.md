# Proposal

## Why

El equipo necesita un workflow común y versionado para trabajar con OpenSpec, ADRs y distintos agentes de IA.

## What Changes

- Documentar el uso de OpenSpec y sus integraciones para OpenCode, Antigravity y GitHub Copilot.
- Mantener los ADRs en `docs/adr/` y contar con una skill para crearlos cuando corresponda.
- Documentar Git Flow y Conventional Commits.
- Agregar una plantilla de Pull Request y hooks de pre-commit.
- Mantener el README y la documentación de instalación actualizados.

## Capabilities

### New Capabilities

Ninguna. Este change configura el workflow de desarrollo.

### Modified Capabilities

Ninguna.

## Impact

Agrega documentación y configuración para el trabajo colaborativo. No implementa funcionalidades de la plataforma ni define su stack.
