# Design

## Decisions

- Mantener frontend y backend en carpetas separadas dentro de la raíz.
- Mantener cada servicio aislado en su carpeta y con sus propios archivos de configuración.
- Mantener el código mínimo enfocado en comprobar que el flujo de desarrollo funciona.

## Non-Goals

- Implementar funcionalidades del dominio.
- Fijar tecnologías no definidas por el equipo.
- Configurar Docker Compose o CI en este change.
