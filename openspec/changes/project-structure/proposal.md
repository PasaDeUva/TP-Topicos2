# Proposal

## Why

El proyecto necesita una estructura de monorepo que permita desarrollar frontend y backend de forma independiente y validar el workflow con código mínimo.

## What Changes

- Crear `frontend/` y `backend/` como carpetas independientes.
- Agregar una implementación mínima en cada parte.
- Validar el flujo end-to-end con el mínimo código necesario.

## Capabilities

### New Capabilities

Ninguna. El change valida la estructura del proyecto, no una funcionalidad de negocio.

### Modified Capabilities

Ninguna.

## Impact

Agrega la estructura inicial del monorepo y código mínimo de validación. No define todavía el stack definitivo ni funcionalidades del dominio.
